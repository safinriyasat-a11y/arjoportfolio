How to Host Your Portfolio

Because this is a high-performance static site, public visitors see whatever is saved in your index.html file. Follow these simple steps:

Step 1: Make your edits Click "Edit portfolio" in the navbar, update your profile info, portrait picture, or add projects.
Step 2: Instant Global Cloud Sync (Recommended) Connect free Firebase Firestore in the Cloud Sync menu. Once connected, every edit you make updates immediately on every phone, tablet, and browser worldwide!
Step 3: Upload to free hosting • GitHub Pages: Push or upload index.html to your GitHub repo, go to Settings > Pages and choose Deploy from branch.
• Netlify: Drag and drop the folder with index.html into netlify.com/drop.
• Vercel: Connect your GitHub repo for automatic continuous deploys.

Connect a free Google Firebase Firestore database so any change you save will instantly update for anyone visiting your website on any phone, laptop, or browser!

⚡ 2-Minute Quick Setup (Free Forever):
  1. Open console.firebase.google.com and click Add Project (e.g. safin-portfolio).
  2. In the sidebar, open Build > Firestore Database > Create Database (choose Start in test mode).
  3. Click Project Settings (⚙️) > General > Your apps > Web (</>), name it "portfolio", and copy the firebaseConfig object.
  4. Paste it into the box below and click Connect & Sync!
